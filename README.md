# 出發前：比賽打包清單

幫助需要帶許多物品到外地參賽的人，依行程建立清單，減少漏帶重要物品的機會。

## 使用方式

下載後，用瀏覽器開啟 `index.html`。不需要安裝套件。

預設情境為高雄三天兩夜、能源實作競賽、天氣偏涼。可變更目的地、天數、目的與天氣，勾選物品、新增物品、篩選未完成項目、複製或列印。瀏覽器會嘗試在本機保存清單；不同裝置不會同步。重新產生清單會重設勾選和自訂項目。

## 與 AI 協作

從使用者真實情境逐步釐清問題，確認最怕漏帶充電線、身分證件、鑰匙，再由 AI 協助設計介面與實作。網頁依固定規則產生建議，沒有呼叫 AI，也沒有查詢即時天氣。競賽器材需依主辦單位規定核對。
